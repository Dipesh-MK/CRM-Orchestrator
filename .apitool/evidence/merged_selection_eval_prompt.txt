TOOLS (names + descriptions only as exposed to orchestrator LLM):
- send_message: Send an SMS message to a recipient phone number via the aggregator. Requires destination phone number in To and message body in Body. A result of pending_user_approval means NOT sent or scheduled yet; tell the user to approve in the UI.
- list_messages: List message audit records across accounts with delivery status, timestamps, and error codes. Masks recipient phone numbers for privacy.
- schedule_message: Schedule a rendered campaign message to be dispatched to a contact at a specified ISO-8601 timestamp. Validates send_at against the virtual clock (must be in future). A result of pending_user_approval means NOT sent or scheduled yet; tell the user to approve in the UI.
- cancel_scheduled_message: Cancel a previously scheduled message job by its job ID before it is dispatched. Sets status to canceled. A result of pending_user_approval means NOT sent or scheduled yet; tell the user to approve in the UI.
- list_scheduled_messages: List scheduled message queue jobs filtered by status (scheduled, sent, failed, canceled). Returns job IDs, contact info, and send_at timestamps.
- create_trigger: Register an automated event trigger rule that executes a send_message action when a typed condition (time, delay, recurring, state, keyword) is met. A result of pending_user_approval means NOT sent or scheduled yet; tell the user to approve in the UI.
- list_triggers: List all active event triggers and automated reaction rules registered on the host orchestrator.
- get_delivery_status: Fetch live delivery status, carrier error codes, and timestamps for a message SID from the host orchestrator delivery reconciler.
