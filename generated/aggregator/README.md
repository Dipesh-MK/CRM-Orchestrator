## Run
```bash
pip install -r requirements.txt
cp .env.example .env   # fill in values; never commit .env
set -a; . ./.env; set +a
python cli.py list
python cli.py call <tool> --args '{"key":"value"}'
python mcp_server.py        # MCP stdio server (what harnesses launch)
```

## Safety defaults
* write/destructive tools are **dry-run** unless `APITOOL_ALLOW_WRITES=1` (or the base URL is localhost / a mock).
* destructive and `confirm: true` tools need the argument `confirm=true` (ask the user first).
* secrets come from the environment only and are redacted from output and logs.
* point the same tools at a mock or sandbox with `APITOOL_BASE_URL=http://127.0.0.1:8080`.
